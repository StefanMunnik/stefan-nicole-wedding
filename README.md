# Stefan & Nicole Wedding

Public RSVP site for 27 March 2027 at Belle Vallee, Wellington.

## Local preview

Open `index.html` in a browser, or from this folder:

```bash
npx --yes serve .
```

## GitHub Pages

1. Create a public GitHub repo (e.g. `stefan-nicole-wedding`).
2. Push the contents of this `site` folder to the repo **root** (not nested in another folder).
3. GitHub → **Settings** → **Pages** → Source: **Deploy from a branch** → `main` / `/ (root)`.
4. Site URL: `https://YOUR_USERNAME.github.io/stefan-nicole-wedding/`
